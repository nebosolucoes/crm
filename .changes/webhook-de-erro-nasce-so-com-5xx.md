titulo: O webhook de erro passa a vir configurado para avisar só falhas do servidor
---
Em instalações novas, o webhook de erro (Admin › Webhook de erro) nasce com o escopo "server", que avisa só falhas do servidor (5xx). Recusas de regra de negócio, como permissão insuficiente ou dado inválido, deixam de virar card por padrão. Quem já configurou o webhook mantém a escolha que fez.
